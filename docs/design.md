# 設計

## 構成

Windows標準の.NET Framework 4.8、C# 5、Windows Formsを採用します。追加の実行基盤やパッケージ復元を不要にし、単体exeとconfigで起動できます。

| ファイル | 責務 |
|---|---|
| `Program.cs` | 起動、同一ユーザー内の単一起動と表示シグナル |
| `TrayContext.cs` | 常駐、5分更新、テーマ・通知選択、Windows通知、終了時の解放 |
| `Alerts.cs` | 閾値・急増・到達予測、メモリ内の観測履歴と通知抑止 |
| `Snapshot.cs` | Obsidian向け表示データ、現在ユーザー限定の名前付きパイプ、時間・出力量の上限 |
| `obsidian/src/` | 固定ツールバー、表示サイズ、鮮度判定、常駐アプリとの連携 |
| `PopupForm.cs` | 使用量と警告帯、ボタン、キーボード、スクロール・DPIレイアウト |
| `Artwork.cs` | 描画補助、サービスの印、埋込アプリアイコン |
| `Models.cs` / `Parsers.cs` | 表示用モデル、欠損値・期間・時刻の解釈 |
| `Providers.cs` | 読み取り専用ファイル処理、固定HTTPS GET、代替情報 |
| `Login.cs` | ユーザー操作による公式CLIのOAuth起動と終了待機 |
| `Theme.cs` | 配色、Windows設定参照、テーマ・通知設定保存、メニュー描画 |

取得はUIスレッド外で実行し、結果をまとめてUIへ反映します。各サービスのエラーを分離し、同時更新を防ぎます。表示中は15秒ごとにリセットまでの時間を描画し直します。

## UI

トレイ左クリックでコンパクトな一覧を開きます。Esc、外側クリック、×で隠し、右クリックメニューから終了します。終了時はタイマー、トレイアイコン、HTTPクライアント、システムテーマ通知の購読を解放します。Windowsシャットダウンを取り消しません。

ライト／ダーク／Windowsに合わせるを選択できます。Windowsのテーマ変更通知はUIスレッドに転送し、開くときにもWindowsの配色設定を読み直します。コントラストテーマを優先します。テーマと通知の設定はアプリ専用 `settings.ini` に保存し、一時ファイルから置き換えます。

警告帯の高さに合わせて一覧を広げ、モニターの作業領域を超える場合はサービス一覧だけスクロールします。見出し・更新ボタン・フッターは固定します。警告文はアクセシビリティ情報とツールチップにも含めます。通知には標準の `NotifyIcon.ShowBalloonTip` を使い、一回の更新を一通知にまとめます。判定条件は [使用量の警告](alerts.md) を参照してください。

アイコンは `assets/app.svg` から生成した16〜256pxのICOを、実行ファイルと埋込リソースに設定します。トレイとフォームで同じデザインを使用します。

## データの境界

入力JSONは不正・欠損・書込途中を想定します。読み取り量とHTTP応答に上限を設けます。「不明」はnullable値で保持し、表示直前まで0%と区別します。ログ由来の値には元の観測時刻を保持します。

秘密情報を表示モデルへ渡さず、例外本文をユーザーへ表示しません。固定宛先・リダイレクト無効・認証ファイルの読取専用を維持します。詳細は [データ取得仕様](data-sources.md) と [プライバシー文書](privacy.md) を参照してください。

Obsidianは `MarkdownView.contentEl` の前に固定ツールバーを挿入します。編集・リーディングの本文領域はそのまま使い、プラグイン無効化時には自身の要素だけを除去します。表示データは常駐アプリが更新完了時に公開し、プラグインは15秒ごとに読むだけです。手動更新は既存トレイの更新イベントへ通知します。詳細は [Obsidianツールバーの設計](obsidian-toolbar.md) を参照してください。
