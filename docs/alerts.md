# 使用量の警告

トレイ版の常駐中に、5分ごとの自動更新と手動更新で判定します。使用中のAIを停止したり、追加クレジットを購入したりする機能ではありません。

警告が多く画面に収まらないときは一覧をスクロールできます。キーボードではPageUp／PageDown、Home／Endを使います。

| 警告 | 条件 | 表示例 |
|---|---|---|
| 上限に近い | 使用量が90%以上、95%以上 | 「週：使用量95%・残り5%」 |
| 上限到達 | 使用量が100%以上 | 「週：上限に達しています」、リセット予定日時 |
| 急増 | 5〜15分離れた観測で10ポイント以上増加 | 「直近10分で +15ポイント」 |
| リセット前の到達予測 | 直近30分の3回以上・10分以上の観測で2ポイント以上増加し、100%になる推定時刻がリセットより早い | 「週：リセット前に上限の見込み」 |

予測は最初と最後の観測間の平均増加速度が続いた場合の推定です。サービス側の保証や利用停止時刻ではありません。リセット日時が不明な場合は予測しません。観測が足りない間も90%・95%・100%の警告は使えます。

## Windows通知

トレイ右クリック → **通知** から選びます。

- **上限・急増・到達予測**：初期設定。すべてを通知します。
- **90%・95%・100%のみ**：割合の到達時だけ通知します。
- **通知しない（画面には表示）**：Windows通知を止めます。警告帯は残ります。

90%・95%・100%は各枠・各リセット期間につき一度ずつ通知します。一度に複数段階を越えた場合は最も高い段階だけ通知します。急増・到達予測は新しく検知した状態を通知し、同じ枠では前回通知から30分以上空けます。新しい割合の段階への到達は待機中でも通知します。

同じ取得時刻を繰り返し読んでも観測回数は増えません。一回の更新の警告を一通知にまとめ、長い場合は上限到達を優先して短縮します。通知をクリックすると一覧を開きます。Windows標準のトレイ通知を使うため、表示・音・表示時間はWindows側の通知設定にも左右されます。

## 古い値・リセット・再起動

判定対象は、取得時刻が直近15分以内で、取得失敗やログイン要求のないオンライン値です。未取得、保存ログ、認証失敗、リセット期限経過、未来にずれた時刻（1分超）は判定しません。元の数値と取得元は引き続き表示します。

プラン変更、リセット予定時刻の2分超の変更、20ポイント以上の減少は新しい期間として扱います。小さな減少でも増加速度の履歴は消します。取得間隔が15分を超えた場合や取得失敗後も速度の観測をやり直します。

履歴は各枠につき直近30分・最大120件をメモリ上だけに保持します。終了すると履歴と通知済み状態は消えます。再起動時にすでに高い使用量であれば再度通知し、予測には再び観測が必要です。通知を再開しても、停止中に判定済みの同じ警告をまとめて送り直しません。

## ウィジェット

中サイズは取得時刻の横に「上限到達」「上限目前」「残りわずか」、大サイズは割合に応じた警告文を表示します。ウィジェット単体では観測履歴を持たず、急増・到達予測・Windows通知はトレイ版の常駐中に利用できます。ボードが最後のカードを保持している間は取得時刻も確認してください。
