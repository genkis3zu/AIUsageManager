# 使用量の警告

トレイ版の常駐中に、5分ごとの自動更新と手動更新で判定します。使用中のAIを停止したり、追加クレジットを購入したりする機能ではありません。

警告が多く画面に収まらないときは一覧をスクロールできます。キーボードではPageUp／PageDown、Home／Endを使います。

| 警告 | 条件 | 表示例 |
|---|---|---|
| 上限に近い | 使用量が90%以上、95%以上 | 「週：使用量95%・残り5%」 |
| 上限到達 | 使用量が100%以上 | 「週：上限に達しています」、リセット予定日時 |
| 急増 | 5〜15分離れた観測で10ポイント以上増加 | 「直近10分で +15ポイント」 |
| リセット前の到達予測 | 直近30分の3回以上・10分以上の観測で2ポイント以上増加し、100%になる推定時刻がリセットより早い | 「週：26% · 90%まで約1.8時間（推定）」 |

予測は最初と最後の観測間の平均増加速度が続いた場合の推定です。サービス側の保証や利用停止時刻ではありません。リセット日時が不明な場合、リセット前に到達するかの警告はしません。観測が足りない間も90%・95%・100%の警告は使えます。

## ペースと到達目安

警告がない場合も、トレイとObsidianでは次の情報を確認できます。

- 現在の使用率、観測した時間幅、増加したポイント数。
- 週枠は1日換算、5時間枠は1時間換算のペース。
- 90%・95%・100%に達するまでの目安と日時。すでに超えた段階は「到達済み」。
- 推定日時よりリセットが早い場合は「リセットが先」。リセット時刻がなければ未取得と明記。

たとえば、現在36%で直近30分に0.25ポイント増えた場合、1時間に0.5ポイント、1日換算で12ポイントです。90%までの54ポイントをそのペースで使えば、約4.5日です。これは取得時点の直近ペースを延長した計算であり、一日全体の平均や実際の作業時間を織り込んだ予測ではありません。表示は次の取得で更新します。

3回以上・10分以上の観測が揃い、0.1ポイント以上の増加があるときに目安日時を計算します。増加なし・小さすぎる増加・1年を超える遠い予測は日時を出さず、増加なし／予測保留と表示します。上限到達の警告通知には引き続き2ポイント以上の増加条件を使い、目安を表示しただけでは追加通知しません。

トレイの青い補足欄は警告ではなくペースの説明です。Obsidianでは標準表示に次の段階までの時間とペースを出し、マウスを重ねると全段階の日時と観測根拠を確認できます。観測が足りないときは「予測の観測中」と表示します。

## Windows通知

トレイ右クリック → **通知** から選びます。

- **上限・急増・到達予測**：初期設定。すべてを通知します。
- **90%・95%・100%のみ**：割合の到達時だけ通知します。
- **通知しない（画面には表示）**：Windows通知を止めます。警告帯は残ります。

90%・95%・100%は各枠・各リセット期間につき一度ずつ通知します。一度に複数段階を越えた場合は最も高い段階だけ通知します。急増・到達予測は新しく検知した状態を通知し、同じ枠では前回通知から30分以上空けます。新しい割合の段階への到達は待機中でも通知します。

同じ取得時刻を繰り返し読んでも観測回数は増えません。一回の更新の警告を一通知にまとめ、長い場合は上限到達を優先して短縮します。通知をクリックすると一覧を開きます。Windows標準のトレイ通知を使うため、表示・音・表示時間はWindows側の通知設定にも左右されます。

## 古い値・リセット・再起動

判定対象は、取得時刻が直近15分以内で、取得失敗やログイン要求のないオンライン値です。未取得、保存ログ、認証失敗、リセット期限経過、未来にずれた時刻（1分超）は判定しません。Grokの認証・通信失敗では値とバーを非表示にします。Claude・Codexの保存値は元の数値と取得元を表示します。

プラン変更、リセット予定時刻の2分超の変更、20ポイント以上の減少は新しい期間として扱います。小さな減少でも増加速度の履歴は消します。取得間隔が15分を超えた場合や取得失敗後も速度の観測をやり直します。

履歴は各枠につき直近30分・最大120件をメモリ上だけに保持します。終了すると履歴と通知済み状態は消えます。再起動時にすでに高い使用量であれば再度通知し、予測には再び観測が必要です。通知を再開しても、停止中に判定済みの同じ警告をまとめて送り直しません。

## ウィジェット

中サイズは取得時刻の横に「上限到達」「上限目前」「残りわずか」、大サイズは割合に応じた警告文を表示します。ウィジェット単体では観測履歴を持たず、急増・到達予測・Windows通知はトレイ版の常駐中に利用できます。ボードが最後のカードを保持している間は取得時刻も確認してください。
