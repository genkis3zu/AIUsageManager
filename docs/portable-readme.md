# AI Usage Manager 1.1.0

Claude・Codex・Grokの使用量を表示するWindows 11用トレイアプリです。

1. ZIP内のファイルを、書き込み可能なフォルダーに展開します。
2. AIUsageManager.exeを起動します。exe.configは同じ場所に置いてください。
3. タスクトレイの棒グラフアイコンをクリックします。見当たらなければ ^ 内を確認してください。

更新は5分ごと。「更新」またはF5でも再取得できます。
トレイ右クリック → テーマで、Windowsに合わせる／ライト／ダークを選べます。
トレイ右クリック → 通知で、すべて／90%・95%・100%のみ／通知しないを選べます。初期設定はすべて通知です。
終了はトレイ右クリック → 終了です。

新しいオンライン値で90%・95%・100%に達すると、Windows通知と画面内の警告で知らせます。急増（5〜15分で10ポイント以上）や、リセット前に上限へ達する見込みも通知します。予測には3回以上・10分以上の観測が必要で、直近の増加速度に基づく推定です。同じ段階を毎回通知せず、急増・予測の再通知は30分以上空けます。通知の表示・音はWindows側の設定にも依存します。

古い保存値や取得失敗時は警告判定しません。ウィジェットは上限に近い状態を文章で表示し、急増・到達予測・Windows通知はトレイ版の常駐中に利用できます。

トレイとObsidianでは、現在の使用率、直近の増加幅、1日または1時間換算のペース、90%・95%・100%までの目安を表示します。取得時点のペースが続く場合の推定で、日平均ではありません。起動後3回・10分以上の新しい観測から表示します。

対応CLIの既存ログインや利用記録が必要です。値がなければ「未取得」になります。

Codex・Grokの認証が必要な場合は「ログイン」ボタンで公式CLIの認証を開始できます。ブラウザで完了すると使用量を再取得します。公式CLIがインストールされている必要があります。
Grokは認証切れや通信失敗時に古いCLIログの使用率へ戻さず、「未取得」としてバーを隠します。
リセット後に使用率だけが省略された場合は、公式画面側の読取応答と現在の週を確認して0%を表示します。追加確認に失敗した場合は未報告のまま扱います。
Windows標準の.NET Frameworkを使用し、追加ランタイムや管理者権限は不要です。
Windowsウィジェットは別のオプションパッケージです。追加手順はGitHubのREADMEを参照してください。
Obsidianも別のプラグインで連携できます。ノート上部に固定した標準3行／縮小1行の表示に対応します。同じソース版のアプリとプラグインを使用してください。
配布ファイルはコード署名されていません。公式ReleaseとSHA-256を確認してください。

ログ・認証ファイルは読み取り専用です。テーマと通知の選択だけをsettings.iniへ保存します。警告用の観測履歴はメモリ上だけに保持し、再起動すると消えます。そのため、再起動時の高い使用量は再通知します。
ログインボタンで起動する公式CLIは、通常の認証と同じように認証ファイルを保存・更新します。アプリはその出力やトークンを保存しません。
